# VARYACVV WISHLIST

## RU  

**Личный вишлист**  
Сайт-вишлист с подарками и заботами, которые я хотела бы получить или сделать.

### Возможности

- Стартовый экран с QR-кодом для доната
- Сетка карточек с пастельными цветами и лёгким наклоном
- Индивидуальная иллюстрация для каждой карточки
- Модальные окна: FAQ, донат и подробности карточки
- Закрытие модальных окон: кнопка '×', клавиша Escape, клик по фону
- Блокировка скролла страницы, пока открыто модальное окно
- Плавное появление карточек и модальных окон
- Адаптивная вёрстка: 4 колонки на десктопе, 2 на планшете, 1 на мобильном
- Доступность: семантический HTML, клавиатурная навигация, focus, aria

### Технологии

- React
- TypeScript
- CSS
- lucide-react

## ENG  

**Personal Wishlist**  
A wishlist site with gifts and care I'd love to receive or do.

### Features

- Entry screen with a donation QR code
- Grid of cards with pastel colors and slight tilt
- Personal illustration for each card
- Action button on each card: modal or external link
- Modal windows: FAQ, donation and card details
- Modal close: '×' button, Escape key, click on the overlay
- Background scroll lock while a modal is open
- Smooth appearance for cards and modals
- Responsive layout: 4 columns on desktop, 2 on tablet, 1 on mobile
- Accessibility: semantic HTML, keyboard navigation, focus, aria

### Tech Stack

- React
- TypeScript
- CSS
- lucide-react
